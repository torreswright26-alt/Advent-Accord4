The current local renderer foundation is Z-Image Base. Renderer R1 is complete
but remains too polite and cartoony. Renderer R2 has been prepared to correct
core-reference weighting, maturity, color behavior, and outline dependence.

The three core aesthetic anchors now outrank historical approval `002` for
renderer-style decisions. Historical approvals remain useful evidence but must
not silently override the newer art direction.
